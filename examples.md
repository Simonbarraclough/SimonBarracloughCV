# Examples and Portfolio Ideas

## Example puzzle

Write a function called `highest_even(numbers)`.

It should:

1. Accept a list of integers.
2. Return the highest even integer.
3. Return `None` if the list contains no even integers.

Example:

```python
highest_even([1, 2, 3, 4])
# returns 4
```

## How to run the project

From the repository folder:

```bash
python tests.py
```

You should see a readable pass/fail report for the correct solution and a deliberately incorrect solution.

## Why this is useful

This project shows a simple but important software pattern:

- define the problem clearly
- write a solution
- test the solution
- report results clearly

That is useful for automation work, small business tools, coding assessments, and AI-assisted evaluation tools.
