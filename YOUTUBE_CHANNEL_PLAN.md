# YouTube Channel Plan - Simon Barraclough

## Channel Positioning

A practical, real-life channel about problem solving, repairs, vehicles, tools, AI, GitHub and building better income skills from scratch.

This should feel honest, useful and relatable - not fake, flashy or over-produced.

## Possible Channel Names

- Simon Builds Better
- Simon Solves It
- Practical Simon
- Fixing It With Simon
- Simon's Practical Progress
- The Real-World Fix
- Driver Builds Digital
- From Driver to Digital

## Best Starting Angle

**Recommended angle:**

> Real-life practical problem solving - cars, repairs, tools, AI help and learning tech to build a better future.

This works because it connects what Simon already does naturally - fixing problems, asking practical questions, working hard, learning tools, and trying to improve income.

## Audience

People who:

- Like practical fixes and real-life problem solving
- Are learning AI, GitHub or tech from the beginning
- Work normal jobs but want better opportunities
- Need help finding parts, fixing things or understanding tools
- Prefer honest progress over fake expert content

## Content Pillars

### 1. Practical Fixes

Examples:

- Finding the exact car grille clip or bolt
- Repairing household appliances
- Measuring parts properly
- Comparing wrong vs right parts
- Tools that actually help

### 2. Learning Tech From Scratch

Examples:

- I built my first GitHub CV
- What is GitHub and why I am using it
- How AI helped me write a CV

- Building small tools that solve real problems

### 3. AI for Real Life

Examples:

- Using AI to find parts
- Using AI to improve a CV
- Using AI to plan a side income
- Using AI to write emails and sort problems
- What AI got wrong and how I checked it

### 4. Driver / Work / Income Improvement Journey

Examples:

- How I am trying to move into better-paid work
- Skills I am learning outside work
- Building a public portfolio
- Honest progress updates
- What I would do differently

## Simple Video Format

Use this structure:

1. Problem: what is wrong or what you are trying to do
2. Attempt: what you tried first
3. Help: how AI, research or tools helped
4. Result: what worked or failed
5. Lesson: one useful takeaway
